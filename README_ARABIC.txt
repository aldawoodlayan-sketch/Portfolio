طريقة تعديل البورتفوليو
======================

1) افتحي index.html لمشاهدة الموقع.

2) إضافة الصور:
ضعي الصورة داخل مجلد المشروع وبنفس الاسم المكتوب داخل المربع في الموقع.
مثال:
images/battlebeam/cover.jpg
images/battlebeam/gun.jpg
images/opnsense/rules.jpg
images/erp/dashboard.jpg
images/packettracer/topology.jpg
images/cinefind/home.jpg

عند وضع الصورة بالاسم الصحيح سيختفي المربع وتظهر الصورة تلقائياً.

3) السيرة الذاتية:
ضعي ملف PDF داخل مجلد resume وسمّيه:
Layan_CV.pdf

4) روابط التواصل:
افتحي index.html وابحثي عن:
LinkedIn
GitHub
your-email@example.com
ثم استبدلي الروابط بمعلوماتك.

5) رفع التحديث على GitHub:
ارفعي الملفات الجديدة إلى نفس المستودع واضغطي Commit changes.
لا تحتاجين إعادة تفعيل GitHub Pages.

مهم:
الأسماء حساسة، لازم تكون الأحرف والامتداد مطابقة تماماً مثل .jpg أو .png.
إذا كانت صورتك PNG، إما تغيرين اسمها في الكود أو تحفظينها JPG بالاسم المطلوب.
