Network Security

OPNsense Firewall Project

A hands-on network security project exploring firewall deployment, configuration, and testing using OPNsense and Firewalld in a virtual environment.

OVERVIEW

Project Summary

A hands-on network security project that explored firewall deployment and management using OPNsense and Firewalld in a virtual environment. The project involved configuring firewall rules, network zones, IP-based access control, traffic monitoring, and troubleshooting common deployment issues. Practical testing was performed to validate firewall behavior, followed by an analysis of real-world enterprise use cases.

Technologies

OPNsense Firewalld VirtualBox Fedora Linux Firewall Rules

HIGHLIGHTS

What the project included

  • Installed and configured OPNsense in a virtual machine.
  • Created and tested firewall rules.
  • Configured Firewalld zones, interfaces, and services.
  • Verified allowed and blocked network traffic.
  • Monitored firewall logs.
  • Resolved networking and firewall configuration issues.
