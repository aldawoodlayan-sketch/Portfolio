IoT · Mobile Application

BattleBeam

Overview

BattleBeam is a home laser tag entertainment system developed as a graduation project. It combines electronic guns, wearable vests, a central hub, and a Flutter application.

The Problem

The goal was to create an affordable and interactive home laser tag experience with real-time communication and score tracking.

The Solution

The system uses infrared communication for hit detection and Wi-Fi with WebSocket for real-time updates between the devices, hub, and mobile application.

Technologies

  • ESP32 and ESP8266
  • Flutter
  • WebSocket and Wi-Fi
  • Arduino IDE
  • Infrared communication

My Contribution

  • System design and implementation
  • Device communication
  • Mobile application support
  • Hardware integration
  • Testing and documentation
