Web Development

Cinefind

A web platform for discovering cinemas in Riyadh and sharing ratings and reviews.

OVERVIEW

Project summary

Cinefind is a cinema discovery platform developed to help users explore cinemas in Riyadh, view cinema details, and share ratings and written reviews. The website includes user login functionality and dedicated pages for AMC, MUVI, and VOX cinemas.

Technologies

PHP MySQL HTML CSS CRUD

HIGHLIGHTS

Key Features

  • Developed user login and account functionality.
  • Created dedicated pages for AMC, MUVI, and VOX cinemas.
  • Implemented a 1–5 rating and written review system.
  • Stored user and review data using MySQL.
  • Contributed to the website development and interface design.
