Cinefind

OVERVIEW

Project summary

A cinema discovery and review platform designed to help users in Riyadh find cinemas, view details, read reviews, submit ratings, and plan their movie outings.

Technologies

PHP MySQL HTML CSS CRUD

HIGHLIGHTS

What the project included

  • Created login and user account functionality.
  • Displayed AMC, MUVI, and VOX cinema information.
  • Implemented cinema reviews and 1–5 ratings.
  • Used MySQL tables for users and reviews.
  • Built and designed the website as part of a team project.
