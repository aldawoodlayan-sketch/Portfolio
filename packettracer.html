HIGHLIGHTS

What the project included

  • Displayed router interfaces and routing tables using CLI commands.
  • Configured GigabitEthernet interfaces and IP addresses.
  • Verified interface status with show commands.
  • Checked connected and OSPF-learned routes.
  • Tested end-to-end connectivity using ping.
  • Saved router configurations to NVRAM.
