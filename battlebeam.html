BattleBeam

OVERVIEW

Project summary

BattleBeam is a portable home-based laser tag entertainment system designed to make laser tag more affordable and accessible. The project integrates custom IR hardware, ESP32 and ESP8266 microcontrollers, IoT communication, and a cross-platform Flutter application. Through the mobile app, players can create teams, configure game settings, and monitor real-time scores on both Android and iOS devices. The system was designed to be portable, rechargeable, compact, and cost-effective while providing an engaging multiplayer experience for indoor environments.

Technologies

ESP32 ESP8266 Flutter WebSocket Arduino IDE Infrared

HIGHLIGHTS

What the project included

  • Built ESP32-based laser guns and ESP8266 wearable vests.
  • Used a central ESP32 hub for game control and WebSocket communication.
  • Displayed live scores, player status, team selection, and game results in Flutter.
  • Performed hardware, software, integration, and acceptance testing.
  • My contribution included hardware, software, documentation, and the README file.
